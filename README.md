# Fake Face Recognition – Scam Face Detection App

## 📌 Background

Di era digital saat ini, kasus penipuan online semakin sering terjadi. Salah satu modus yang mulai banyak digunakan adalah menggunakan foto atau wajah orang lain untuk melakukan scam, penipuan identitas, hingga manipulasi visual di media sosial maupun platform komunikasi.

Banyak orang merasa kesulitan membedakan apakah wajah yang muncul pada sebuah gambar benar-benar asli, hasil manipulasi AI, atau digunakan untuk tujuan penipuan. Hal ini menimbulkan keresahan karena identitas seseorang dapat disalahgunakan dengan mudah.

Berangkat dari keresahan tersebut, dibuatlah aplikasi **Fake Face Recognition**, sebuah aplikasi berbasis AI yang membantu mendeteksi apakah wajah pada gambar termasuk wajah asli atau berpotensi fake/scam.

---

## 🚀 About The Project

Fake Face Recognition adalah aplikasi berbasis Machine Learning yang digunakan untuk mendeteksi wajah asli maupun wajah palsu/scam dari sebuah gambar.

Aplikasi ini dibangun untuk membantu meningkatkan awareness terhadap:

* Identity fraud
* Scam berbasis visual
* Penyalahgunaan foto orang lain
* Deepfake dan manipulasi wajah

User hanya perlu mengunggah gambar wajah, kemudian sistem akan melakukan analisis dan memberikan hasil prediksi.

## 📷 How It Works

1. User mengunggah gambar wajah
2. Sistem memproses gambar
3. Model AI melakukan prediksi
4. Hasil klasifikasi ditampilkan:

   * Real Face
   * Fake Face
